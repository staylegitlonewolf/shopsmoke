How TV updates work

Publish Now switches the server's active revision. Online TV browsers check for changes every second, report which menu they are showing, and reload the full player every 15 minutes. Each TV card shows when that TV last checked in. "Publish Later" stores the release date in UTC and applies the change on the next server check at or after that time — or within a minute if the optional cPanel cron job from DEPLOY.md is set up. Use History on a TV card to put an earlier menu back on air. An offline TV retains the previously loaded content until it reconnects.

Deployment status: This panel manages the optional PHP server only after the owner has set a setup key and completed authentication. No Inventory Master / retail OS data is modified.
